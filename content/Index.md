Stokhastik Garden est un espace de recherche, d'écriture et de réflexion dédié à ma thèse de master en Media Design à la HEAD, réalisée entre juin et décembre 2026.

## Comment ça marche

5 catégories de documents : 

| Catégorie         | Description                                | Exemple                                |
| ----------------- | ------------------------------------------ | -------------------------------------- |
| **Concepts**      | Terminologies, concepts, vocabulaire, etc. | Cosmogramme, ANT, etc.                 |
| **Documentation** | Présentation, résumé, protocoles           | Présentation de la recherche           |
| **Fragments**     | Fragment de données                        | Utilisés dans les textes               |
| **Journal**       | Données subjectives                        | Ressenti, doutes, .etc.                |
| **Sources**       | Données objectives                         | Lecture, entretien, observations, etc. |
| **Écriture**      | Textes produits                            | What The Fuck Am I Doing Here          |

L'objectif du présent blog est de pouvoir retracer le réseau d'acteurs que constituent ces multiples sources, qu'il s'agisse d'observations, de lectures, d'observations, ...
